# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## In short

- Be respectful and welcoming, whatever someone's experience level, background or identity.
- Discuss code and ideas, not people. Disagreement is fine; harassment, insults and personal attacks are not.
- No sexualised language or imagery, trolling, or publishing anyone's private information.
- Help newcomers, and accept constructive feedback gracefully.

## Scope

This applies in all project spaces (issues, pull requests, discussions) and whenever someone represents the project in public.

## Reporting

If someone's behaviour is a problem, contact the maintainer, [@BenScriptsRBX](https://github.com/BenScriptsRBX), privately on GitHub. Reports are kept confidential. Depending on what happened, the response can range from a warning to a permanent ban from the project, following the Contributor Covenant's enforcement guidelines.
